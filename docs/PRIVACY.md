# PHPLoader のデータと通信

対象: PHPLoader 1.0.1 / Windows 版。公開元: [USAPICO](https://usapico.com/)。

PHPLoader 本体には、利用状況の解析、広告、アカウント登録、クラウド同期、クラッシュ情報の自動送信、自動更新確認を実装していません。編集したファイルを USAPICO に送信する機能はありません。

## このパソコンに保存するもの

標準の保存場所は `%APPDATA%\PHP Loader` です。エクスプローラーのアドレス欄に入力して開けます。テスト用の環境変数で保存場所を指定した起動では、その指定先を使います。

| 保存内容 | 保存場所・目的 |
| --- | --- |
| タブ、ファイルのパス、編集中の本文、保存済み本文、ブックマーク、設定 | `session.json`。次回起動時の作業復元に利用。`session.json.bak` にバックアップを保存し、破損データを `session.recovery-*.json` として保全する場合があります。これらも暗号化せず保存します |
| 追加したスニペット拡張 | `extensions` フォルダー |
| 最初にコピーするサンプルと、そのサンプルで作成・保存したファイル | `workspace` フォルダー |
| 起動失敗時の日時・エラー詳細 | `startup-error.log`。障害によってファイルのパスを含むことがあります |
| プレビューの Cookie、キャッシュ、Web ストレージなど | Electron / Chromium が管理する同じデータフォルダー内のファイル |

**下書きと作業状態は暗号化せず保存します。** 未保存の編集内容にもパスワード、API キー、個人情報などが含まれる場合があります。パソコンの他の利用者に渡すとき、バックアップするとき、問い合わせにファイルを添付するときは、その内容を確認してください。アプリの下書き復元は、元ファイルのバックアップを保証するものではありません。

ユーザーが保存したファイルは、保存先に直接書き込みます。設定フォルダーの削除だけで、別の場所に保存したファイルが消えることはありません。

## 通信が発生する場面

ローカルサーバーは `127.0.0.1` で待ち受けます。通常の構成では、同じパソコンから利用する開発用サーバーです。インターネット公開用サーバーではありません。

表示・実行するコンテンツの内容によっては、外部へ通信します。たとえば HTML / Markdown に含まれる外部画像、CSS や JavaScript の読み込み、HTMX のリクエスト、PHP の外部 API 呼び出しがあります。接続先には IP アドレスやリクエスト内容が伝わる可能性があります。PHP は現在の Windows ユーザーの権限で動作し、アプリのプレビュー隔離機能は PHP 自体のファイルアクセスや通信を制限するものではありません。

「ブラウザーで開く」や公式サイトへのリンクを選ぶと、既定のブラウザーを開きます。ブラウザーやアクセス先のサービスには、それぞれの設定・規約・プライバシーポリシーが適用されます。Web サイトからのダウンロード時のアクセス記録も、このアプリのデータ保存とは別です。

## データを消す・持ち出す

1. 残したい下書きを保存し、`workspace` 内で作ったファイルを含め、必要なデータを別のフォルダーへバックアップします。
2. ローカルサーバーを停止して、PHPLoader を終了します。
3. `%APPDATA%\PHP Loader` を削除すると、設定、下書き、拡張機能、キャッシュ、同フォルダー内のサンプル作業ファイルを削除できます。
4. アプリ自体を削除する場合は、展開した PHPLoader の配布フォルダーを削除します。

配布フォルダーだけを移動・削除しても、標準のデータ保存場所には設定や下書きが残ります。完全に USB メモリー内だけで完結する保存方式ではありません。
