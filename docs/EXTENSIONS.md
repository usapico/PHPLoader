# 拡張機能をつくる

PHPLoader の拡張機能 API v1 は、**JSON によるスニペット集**です。拡張機能画面から JSON ファイルを追加すると、よく使うコードをエディターへ挿入できます。

`examples/custom-extension.json` をコピーして、名前とコードを編集するところから始められます。JSON は UTF-8 で保存してください。

```json
{
  "id": "my-project-kit",
  "name": "My Project Kit",
  "version": "1.0.0",
  "description": "プロジェクトでよく使うコード",
  "author": "Your name",
  "snippets": [
    {
      "id": "hello",
      "title": "あいさつ",
      "language": "php",
      "body": "<?php echo 'こんにちは'; ?>\n"
    }
  ]
}
```

## 項目

| 項目 | 形式 |
| --- | --- |
| `id` | 必須。64 文字以内の一意な識別子。英小文字で始め、英小文字・数字・`-`・`.` を使用。区切り記号の連続や末尾への配置は不可 |
| `name` | 必須。表示名、80 文字以内 |
| `version` | 必須。`1.0.0`、`1.0.0-beta.1` などのセマンティックバージョン、64 文字以内 |
| `description` | 必須。説明、500 文字以内 |
| `author` | 任意。作者名、100 文字以内 |
| `snippets` | 必須。1〜100 件のスニペット |

各スニペットには `id`（上記と同じ形式、拡張機能内で一意）、`title`（100 文字以内）、`language`、`body` を指定します。空の本文は使えません。本文は 1 件 50,000 文字以内、合計 500,000 文字以内です。文字数は JavaScript の文字列長で数えます。

`language` は `php`、`html`、`htmx`、`markdown`、`javascript`、`typescript`、`css`、`json`、`text` に対応します。JSON の文字列内では改行を `\n`、ダブルクォートを `\"` と記述してください。本文はそのまま挿入され、変数やプレースホルダーは展開されません。

## 動作と境界

- インストール時に形式・識別子・サイズを検証し、不明な項目は拒否します。
- 拡張機能はコードのひな形を追加します。インストール時に JavaScript、PHP、コマンドを実行することはありません。
- `main`、`activate`、`command`、`builtin` などのフィールドは利用できません。JavaScript を含むスニペットも、拡張機能自体の実行コードにはなりません。
- 挿入したコードを保存してローカルサーバーで開けば、通常のプロジェクトコードとして実行されます。実行するコードは内容を確認してください。
- HTMX 用スニペットには HTMX ライブラリが必要です。サンプルプロジェクトには `assets/htmx.min.js` を同梱しています。新しいプロジェクトにもライブラリを配置して読み込んでください。
- 拡張機能のオン / オフで、スニペットを有効 / 無効にできます。

独自の画面、サーバーフック、コマンド実行などは API v1 の対象外です。将来の API で追加できるよう、マニフェストを検証する層とアプリ本体を分離しています。
