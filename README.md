# PHPLoader

**PHP・HTML・HTMX・Markdown を、ひとつの画面で編集・プレビュー。**

PHPLoader は、ファイルをタブで開き、コードと表示結果を並べて確認できる Windows 向けの無料デスクトップアプリです。提供元は [USAPICO](https://usapico.com/) です。

このリポジトリでは、アプリの配布、使い方、更新情報を公開しています。開発用のソースコードは含めていません。

## はじめに

1. 上のリンクから `PHPLoader-1.0.1-windows-x64.zip` をダウンロードします。
2. ZIP を**すべて展開**し、展開先の `PHPLoader.exe` を起動します。同じフォルダーの DLL や `resources` も必要です。
3. 最初に開くサンプルを試すか、**フォルダーを開く**から自分のプロジェクトを選びます。
4. **コード / 分割 / プレビュー**で表示を切り替えます。PHP を実行する場合は、設定で `php.exe` を指定し、**サーバーを起動**を押します。

PHP がなくてもコード編集、Markdown プレビュー、HTML 用の静的サーバーを利用できます。インストーラーではありません。GitHub が自動生成する `Source code (zip)` はアプリ本体ではないので、上記の Windows 版 ZIP を選んでください。

## 主な機能

- PHP・HTML・HTMX・Markdown・CSS・JavaScript などのコード編集
- コード表示、プレビュー表示、分割表示
- タブの並べ替え・固定、ファイルのブックマーク
- 検索・置換、コマンド検索、ライト / ダークテーマ
- PHP / HTML 用ローカルサーバーの起動・停止とログ表示
- タブ・下書き・設定の復元、外部変更との保存競合の検出
- 後から追加できる JSON 形式のスニペット拡張

現在の拡張機能は JSON スニペット集です。任意のプラグインコードを読み込む機能ではありません。編集対象は UTF-8 のテキストファイルで、1ファイル最大8 MiBです。

詳しい使い方は [利用ガイド](USER-GUIDE.md)、拡張の作り方は [拡張機能ガイド](docs/EXTENSIONS.md) をご覧ください。

## データとローカルサーバー

設定・下書きなどは、通常 `%APPDATA%\PHP Loader` に保存します。下書きは暗号化しません。アプリ本体に広告・利用状況解析・クラウド同期・自動更新確認は実装していません。[保存先と通信について](docs/PRIVACY.md)

ローカルサーバーは同じパソコンでの開発・確認用です。PHP は利用者の権限で実行されるため、信頼できるプロジェクトで使用してください。PHP 本体、データベース、Composer は同梱していません。Apache の `.htaccess` や未解決URLの自動フロントコントローラー振り分けには対応していません。
